# Raíces Multiespacio

Sitio web estático del salón de eventos Raíces Multiespacio, en Corrientes. Presenta el salón, la galería cubierta con parrilla y el parque: hasta 140 personas, con fotos del lugar y consulta por WhatsApp.

**En vivo:** https://raicesmultiespacio.vercel.app

## Deploy

El sitio es HTML, CSS e imágenes estáticas. No hay framework ni paso de build.

Vercel despliega automáticamente cada push a `main`. `index.html` está en la raíz del repositorio, junto con las carpetas `fotos/` y `logos/`.
